See what changed between two revisions of a drawing.

Lightable compares two DXF files and lists every change in plain words, not just the one inside the revision cloud.

1. Find what changed

Drop in two revisions and see every change on one overlay.

  • Drag Rev B and Rev C onto the page. Nothing to install.
  • The overlay colours each change: blue added, red deleted, yellow changed.
  • "10 changes found between Rev B and Rev C". The revision cloud marks only one of them.

2. Every change explained

Each change in plain words, with the exact values one tap away.

  • Tap a change in the list and the drawing zooms to it: "Circle diameter changed from 13.5 mm to 17.5 mm".
  • Details shows the exact values behind each line, such as how far a centre moved and the old and new radius.
  • Lightable describes the geometry it detects. You judge what it means.

3. Before and after

Both revisions next to each other, the right way round.

  • Revision marks in the file names ("Rev B", "_C", "v3") or the file dates decide which file is the earlier one.
  • When the names and dates don't say, Lightable asks which file is earlier.
  • Side by side shows both revisions with one shared zoom; Swap compares the other way round.

4. Share a review report

A PNG for people and a JSON file for records and scripts.

  • The PNG report holds the summary, the colour legend, the overlay, the changes (as many as fit, with a count of the rest) and what was not compared.
  • The JSON file lists every change with its exact old and new values.
  • Both are made in your browser and saved as ordinary downloads (Details, then Export).

5. Private, honest, anywhere

Your files stay on your computer, and Lightable says what it does not check.

  • "Files are read in this browser, never uploaded."
  • "What isn't compared?" opens the list of what the comparison skips.
  • A DWG file gets a plain message: save it as DXF in your CAD program. It also works on a phone.

Why 10 changes?

In the example, one engineering decision changed the bracket: the bolts went from M12 to M16 for a higher load. One decision, several changes in the drawing:

  • The four clearance holes grew from Ø13.5 to Ø17.5 mm (the medium-series clearance for M16).
  • The bigger holes need more edge distance, so each hole moved 5 mm inward. The edge dimensions went from 20 to 25 mm (two dimensions) and the hole pitch from 120 × 60 to 110 × 50 mm (two more).
  • The hole callout changed from "4x Ø13.5 THRU" to "4x Ø17.5 THRU".
  • The bolt note changed from "BOLTS: 4x M12" to "BOLTS: 4x M16".

That is 4 holes, 4 dimensions, the callout and the note: 10 changes. The drafter clouded only the bolt note, so the holes a mating part has to match went unclouded. The revision letter, the revision-table row, the cloud and the triangle are listed separately as revision markup (8 items).

Works with

  • DXF from R12 to 2018 (AC1009 to AC1032), as text (ASCII) DXF, from any CAD program that exports DXF.
  • Units: changes are given in the drawing's own units (mm, cm, m, in, ft and others, from the file's units setting); a file without units gets plain numbers.
  • File size: everyday drawings open in a moment. A 50 MB drawing with 275,000 entities took 34 s to open in Chrome and 47 s in Firefox on a two-core laptop.
  • Not yet: DWG and binary DXF. Save the drawing as (text) DXF in your CAD program; Lightable says so when you drop one.

How it decides what changed

Lightable compares the drawing data, not pictures of it.

  • Each entity in Rev B is matched with one in Rev C. When the two files share their internal handles (most edits keep them), matching uses the handles first.
  • Otherwise, or for anything left over, it matches by content: identical entities, entities moved by one shared offset, the same geometry with other properties (layer, colour), and finally nearby entities of the same type and layer. A guess between several candidates is marked uncertain.
  • Numbers closer than a millionth of the drawing's size count as equal, so re-saving a file doesn't produce changes. Handles, timestamps, the order of entities and the way numbers are written are never reported.
  • Shapes saved differently but drawing the same lines (a polyline saved as separate lines) are counted as "redrawn", not as changes.
  • What is left over is added or deleted.

Measured: on 12 test pairs of scripted edits, all 28 expected changes were found, with none missed and none extra. Three pairs of the same drawing (renumbered, saved as another DXF version, re-saved by another program) report no geometry changes.

Privacy

  • Lightable runs in your browser. The files you open are read there and never uploaded.
  • The page's security policy only allows this site's own files, so it cannot send your data anywhere else.
  • Check it yourself: open your browser's developer tools, go to the Network tab, then open two files. No request carries your drawing.
  • No tracking, no analytics, no cookies. The code is open source: github.com/lightable-dev/lightable.

Honest limits

Not compared yet (each comparison lists these too, under "What isn't compared?"):

  • text styles
  • dimension styles
  • linetype definitions; the linetype names entities use are compared
  • other tables (APPID, UCS, VIEW, VPORT)
  • drawing settings other than units ($INSUNITS) and linetype scale ($LTSCALE)
  • objects (layouts and page setups, dictionaries, groups, ...)
  • anonymous blocks (dimension pictures, ...); the dimensions themselves are compared

Lightable does not say whether a change is right, whether a drawing is ready to build from, or whether a revision cloud covers every change. It reports what differs in the data; you judge what it means.

Questions

Is it free?

Yes. Lightable is open source under the MIT or Apache 2.0 licence.

Do I need to install anything?

No. It runs in the browser on computers and phones. A desktop app can be built from the source code.

Are my drawings uploaded?

No. They are read in your browser and stay on your computer; see Privacy above for how to check.

Which CAD programs does it work with?

Any program that can save a DXF file (R12 to 2018). For a DWG file, save it as DXF first.

Can it tell me whether a change is correct?

No. It lists what changed, exactly; whether that is what was intended is your call.

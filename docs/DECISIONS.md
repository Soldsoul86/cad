# Decisions

Choices the spec left open, and why. Follow these unless a later entry here
replaces one. When you make a new call the spec doesn't cover, add it here.

## M1

1. **Unknown data keeps raw text.** `Unknown` entities, raw tables, raw
   sections, header variables and `extra` lists store each value as the
   original text (`Pair { code, raw }`), not as a parsed `Value`. This lets
   the M3 writer reproduce unknown data byte-for-byte. `Unknown::group_codes()`
   and `Pair::value()` give the typed view. (The spec sketched
   `Vec<(i16, Value)>`.)
2. **Header values are accessors.** `Header` holds every variable in file
   order; `version()`, `insunits()`, `extmin()` etc. read from that list, so
   there is one source of truth.
3. **Known entities keep leftovers in `extra`.** Codes a parsed entity doesn't
   use (XDATA, `102 {...}` groups, `999` comments, unrecognised codes) go into
   `Entity::extra` in file order. Subclass markers (`100`) are dropped; the
   writer regenerates them. `Layer::extra` works the same way.
4. **Malformed → `Unknown` + warning.** A bad number, missing required field,
   negative radius, or invalid colour, lineweight, handle or flag turns a known
   entity into `Unknown` (all pairs kept) with a warning. Zero radius is
   accepted.
5. **Duplicate table names:** the first entry wins; the duplicate is kept in
   `Table::unparsed` with a warning.
6. **Damaged files:** a tokenizer error after the first `0 SECTION` keeps
   what was read plus a warning; garbage before any section is
   `DxfError::NotDxf` or a syntax error. Missing `ENDSEC`, `ENDTAB` and `EOF`
   are warnings.
7. **Arc angles** are stored in degrees, as in the file.
8. **`999` comments outside sections** are dropped silently (the format
   allows them anywhere; they carry no drawing data).
9. **Licence:** `MIT OR Apache-2.0`, with `LICENSE-MIT` and `LICENSE-APACHE`.
10. **Versions:** `Version` covers R12 and 2000–2018. Other `$ACADVER` values
    (e.g. R13/R14) still load, with a warning; `Header::acadver()` returns the
    raw string.
11. **Encoding (interim):** input that isn't valid UTF-8 is decoded as Latin-1
    with a warning, until `$DWGCODEPAGE` handling lands in M2.

Also settled:

- **No `dxf` crate.** The reader is written from scratch with no dependencies;
  the spec's "evaluate the `dxf` crate" step was dropped after M1.
- **Corpus:** `tests/corpus/` is generated by `tools/gen_corpus.py` (keep them
  in sync). Files that can't be redistributed go in the git-ignored
  `tests/corpus-private/`; the corpus tests load them when present.
